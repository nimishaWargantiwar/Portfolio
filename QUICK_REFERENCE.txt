================================================================================
                        HOW TO GET RESUME LINK
================================================================================

Google Drive:
  1. Upload resume.pdf
  2. Right-click → Share → Copy link
  3. Change "view?usp=sharing" to "uc?export=download&id=FILE_ID"
  4. Paste in src/config.js

Alternative:
  Use Dropbox, GitHub, or any hosting service
  Must be a direct download link

================================================================================
                          TROUBLESHOOTING
================================================================================

Q: npm not found?
A: Install Node.js from nodejs.org

Q: Port 3000 in use?
A: Edit vite.config.js, change port to 3001

Q: Styles not loading?
A: npm install
   npm run dev

Q: Links don't work?
A: Check src/config.js - don't use "#" as final URL

Q: Build error?
A: Make sure you're in the right directory
   Run npm install again
